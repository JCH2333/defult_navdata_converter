# 游戏内测试清单

请记录每项 `通过 / 失败 / 未测试`，并附机场、航路、程序名称及截图或日志。

## 基本加载

- [ ] 模拟器正常启动，没有导航数据加载错误。
- [ ] 搜索 `ZBCF`、`ZUNZ`、`ZUUU` 均能返回机场。
- [ ] 退出飞行回到主菜单无崩溃。
- [ ] 完全退出模拟器无崩溃。

## 机场与跑道

- [ ] `ZBCF`、`ZUNZ`、`ZUUU` 的机场信息和跑道显示合理。
- [ ] 能设置出发机场和到达机场。

## 程序

- [ ] 至少选择一个已确认可用的 SID。
- [ ] 至少选择一个已确认可用的 STAR。
- [ ] 至少选择一个已确认可用的 ILS 或 RNAV 进近。
- [ ] 程序腿顺序、航点名称和航向没有明显异常。

## 航路与导航台

- [ ] 创建一条普通中国区域航路。
- [ ] 航路点顺序和航路连接没有明显断裂。
- [ ] 搜索一个 VOR、一个 NDB 和一个普通航点。

## 重启与边界稳定性

- [ ] 重启模拟器后重复机场和航点搜索。
- [ ] 试验一个包含已知边界端点的航路，仅确认不会导致数据库或模拟器崩溃。
- [ ] 记录任何加载失败、空白列表、程序崩溃或退出异常。
