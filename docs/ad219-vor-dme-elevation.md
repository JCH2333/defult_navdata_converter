# AD 2.19 VOR/DME 高程补充

适用周期：2608R1。

AD 2.19 机场无线电导航设施表不提供可验证的设施磁差，因此不能新增、重区域化或修改任何 VOR 本体记录。它只能补充已由当期 `VOR.csv` 完整识别的 VOR 的 DME 天线高程，并且必须同时满足：

1. 仅处理 `VOR.csv` 的直接 VOR。
2. AD 2.19 证据按大写标识和频率唯一匹配。
3. 424 VOR 与 AD 2.19 证据的坐标大圆距离不超过 `0.01 NM`。
4. PDF 明确打印唯一 DME 高程，并保存其页码和 SHA-256 来源。

补充只写入 BGL 的 `Vor/Dme.alt`。VOR 的坐标、磁差、区域、频率、名称和身份均保持 424 原值；任何歧义、坐标偏离或缺失高程均不补充。
